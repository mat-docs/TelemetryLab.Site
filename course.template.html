What it covers

Four things a bare Kafka topic has no concept of

You can move numbers with Kafka alone. What you cannot do is say what a number is — its units, its valid range, how fast it arrives, which session it belongs to, and what happened during it. Each module is one of those, taught by making you build it and then break it.

How it runs

You work in your own repository

Take a copy of the lab from the template — it becomes a repository you own, with the validation bot already in it. Open a Codespace on it, or clone it and run locally if you would rather.

Each module asks for a change. Run lab check to grade it on your own machine in seconds, then lab submit to branch, push and open a pull request. The bot runs the whole pipeline again on a clean machine, comments with what it found, and on a pass advances you to the next module and merges.

lab check runs the identical code the bot runs, so a pass locally is a pass in CI. There is no reason to ever push a guess. 

# once, when the Codespace opens
docker compose up -d --wait kafka stream-api key-generator

# for every module
lab check     seconds, on your machine, nothing pushed
lab submit    branch, push, open the pull request

What is the ATLAS Telemetry Lab?

Free coding exercises that teach how a real-time telemetry pipeline works, by making you run one and change it. You copy a repository, open it in a browser IDE, and a broker, a streaming API and a simulated car start up. You edit code; a bot runs it against the pipeline and reports what happened.

What is ATLAS Open Streaming?

The platform the lab runs on, from Motion Applied. A producer sends data over gRPC to a Stream API, which registers the session, holds the configuration describing each channel, and writes to Apache Kafka. Any number of consumers read from there.

Do I need an ATLAS licence?

Not for course 01. The three images it runs — Apache Kafka, the ATLAS Stream API and the Key Generator — are public on Docker Hub and pull with no account or licence key; that is how the automated validation runs every time. ATLAS Viewer, the commercial desktop application, is not used. If a later course needs a licensed component, its own page will say so.

What does it cost?

We charge nothing. The compute is GitHub's and comes out of your own allowance: Actions is unlimited on public repositories and 2,000 minutes a month on private ones, and Codespaces gives personal accounts 120 core-hours a month free, or 180 on Pro. On the 2-core machine this uses, 120 core-hours is 60 hours of run time.

How long does course 01 take?

We do not know yet, and any figure we gave you would be invented. Nobody outside the team has run it start to finish. What is measured: four modules, a Codespace that takes about three and a half minutes to become usable, and a validation run of roughly two minutes each time you submit. We will publish a real number when we have one.

What do I need installed?

Nothing, if you use a Codespace — it arrives with Docker, Python 3.12 and Node 22 in it and the container images already pulled. To work on your own machine instead you need those three, and the same docker compose up brings the stack up.

How is my work marked?

A GitHub Actions workflow in your own repository runs the whole pipeline against what you wrote and comments on your pull request. It grades behaviour, not shape: it never looks for a particular line of code, it runs the thing and checks what it did. Solve a module a different way and it still passes.

Does my repository have to be public?

No. It is your repository and the choice is yours. Public means the Actions minutes are unlimited and your work is linkable, which is the point of the completion page. Private works too, and draws on your 2,000 free minutes a month.

Do I need to know anything about motorsport?

No. The simulated car is a convenient source of realistic multi-rate data with laps and events in it. Motion Applied document ATLAS as being used in motorsport, aerospace, research and robotics, and the ideas here — sessions, parameter definitions, contiguous timestamps, markers — do not depend on the domain.

Can I use a language other than Python or JavaScript?

Yes, from Module 04. The producer and the reference consumer are Python and JavaScript, but the wire format is protobuf over Kafka and the definitions ship in the repository. Module 04 compares what your consumer reports against what the producer recorded sending, whatever you wrote it in.

Who made this, and why?

Motion Applied, who build ATLAS. The honest reason: engineers who learn telemetry on a platform tend to reach for it again later. The stack the courses use is free and public either way, and everything you write stays yours.

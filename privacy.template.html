Privacy

What we collect

Two things, and only one of them by default. This page lists both, field by field.

This site

Page views, without cookies

The site uses Google Analytics to count page views and clicks on the start-course buttons. It runs with consent set to denied for every storage type, so no cookies are set for analytics; Google counts from cookieless pings instead, which makes the numbers approximate. There is no cookie banner because nothing here asks for consent.

The course

Progress, only if you say yes

The course runs in a repository you own. The first time you run lab submit it asks once whether to share anonymous progress. Say nothing, or no, and nothing is sent. Say yes and the grading workflow sends, each time it grades a pull request:

  • the module number
  • pass or fail
  • the course name
  • the template version
  • a random ID generated for that copy of the course

It does not send your GitHub username, the repository name, or any code. The ID is random and is not derived from anything about you.

Our endpoint

What it sees and does not keep

The request carries a short-lived GitHub Actions token so our endpoint can check it came from a real grading run and not from anything else. That token contains the repository name. The endpoint reads it only to verify the request; it does not log it and does not store it.

We keep no record of our own. The event is forwarded to Google Analytics and that is the only place it exists.

Turning it off

One command

# in your repository
lab share off

It takes effect from your next submit. lab share on turns it back on; lab share status shows which you are on.

Questions about any of this: open an issue on the course template repository.
